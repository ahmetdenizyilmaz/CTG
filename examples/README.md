# CTG listening room

Open these projects with CTG's **Demos** view or File → Open. Each one is editable.

| Song | Length | What to explore |
|---|---|---|
| [Afterglow Circuit](afterglow-circuit/Afterglow%20Circuit.sbproj) | 1:50 | Deliberately AI-authored emotional/funk song; 325 native MCP calls, no random composer |
| [Electric Signals](electric-signals/electric-signals.sbproj) | 0:32 | Composer v2 funk, breakbeat and walking bass |
| [Neon Satellites](neon-satellites/neon-satellites.sbproj) | 0:42 | Composer v2 half-time title theme |
| [Neon Footsteps](neon-footsteps/neon-footsteps.sbproj) | 0:30 | Composer v2 adventure melody and octave bass |

Lengths include instrument release/reverb tails. All audio is synthesized by the
native engine. The AI-authored project includes its MCP client, literal score and
mix revision script. The original `songs/` examples are retained from the engine.
